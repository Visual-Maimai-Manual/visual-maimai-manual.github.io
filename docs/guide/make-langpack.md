# 制作语言包
目前来看，Visual Maimai的官方支持语言有简体中文和英语，如果你发现这里面没有你的语言（或是有一定基础，想给Visual Maimai做翻译），那么欢迎你来。  
  
简体中文的语言包似乎是内嵌在Visual Maimai内的，所以需要根据英文语言包进行修改。  
一般情况下，Visual Maimai的语言包在```(软件目录)\Languages\```下。
Visual Maimai的语言包是INI格式，打开之后可以看到是这样：
```
English
rm_paren=(Right Click)
lm_hold_to_draw=*Hold Left button to draw
bpm_calc=BPM Calculator
note_act=Note Action
<…220 more>
```
可以看出来，第一行代表的是语言名，同时也是在“偏好设置——语言”内显示的语言名。
  
制作完成之后，请在Discord官方服务器内于对应语言的general频道内（没有对应语言就直接发到#general），收集各位玩家的反馈并进行修改。
