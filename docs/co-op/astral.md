# 内网穿透：Astral
> [!TIP]
> Astral其实更适合中国大陆内的联机写谱，如果你同时需要与处于中国大陆外的好友写谱，请使用[Zerotier](zerotier.md)

Astral是一个虚拟互联网工具，虽然设计出来是为了游戏，但与Easytier相比较为稳定且拥有多个服务器。
## 下载
Astral本体可于[Astral官网](https://astral.fan/)下载。
## 发起
Astral的界面默认中文。
在侧边的选项内，选择“设置”，点击“服务器列表”，把侧边为绿的服务器全部启用。  
在侧边的选项内，选择“房间”，随后点击右下角的“+号”创建一个房间，名字随便取。  
随后选择创建好的房间，点击分享，点击复制链接，随后发给好友~~让好友一脸懵~~。  
最后回到主页，点击链接并在Visual Maimai内开启谱面共享，设置端口号（0~65535）并告诉好友。
## 加入
把好友发来的~~让你一脸懵的消息~~链接复制下来，打开Astral。  
在侧边的选项内，选择“设置”，点击“服务器列表”，把侧边为绿的服务器全部启用。  
在侧边的选项内，选择“房间”，随后点击右下角的剪切板符号，把~~让你一脸懵的~~链接粘贴上去，导入后即可看到好友的房间。  
随后选择导入的房间，回到主页，点击链接后应当看到好友。  
最后复制下来好友的虚拟IP地址（直接点击好友的名字），打开Visual Maimai并选择“加入谱面共享”，输入```虚拟IP地址:好友给你发来的端口号```，最后加入。
