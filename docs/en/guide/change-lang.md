# Change Visual Maimai's Language
If you see Visual Maimai's UI is Chinese (Just like 就像这样), then you need to change the UI language manually.
  
Because Chinese is a completely different language from English, here is a pictorial guide:  
![1](/en/photo/change-lang1.png)  
![2](/en/photo/change-lang2.png)   
![3](/en/photo/change-lang3.png)   
![4](/en/photo/change-lang4.png)   
Then tap the blue button, and the UI will be in English.
