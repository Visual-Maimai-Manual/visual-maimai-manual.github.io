# 内网穿透：Zerotier
> [!TIP]
> Zerotier其实更适合多个地区的联机写谱，如果你只需要与处于中国大陆的好友写谱，请使用[Easytier](easytier.md) 
> Zerotier is better of muiti-region's CO-OP,if you only need to use it with China Mainland's friends,please use [Easytier](easytier.md).

Zerotier是一个虚拟局域网工具。  
Zerotier is a VLAN tools
## Download
可以在[Zerotier官网](https://www.zerotier.com/download/)下载Zerotier客户端。  
You can Download Zerotier Client at [Zerotier's official website](https://www.zerotier.com/download/).
## Create LAN
访问[Zerotier官网](https://www.zerotier.com/)，点击右上角的“Start for Free”，注册一个账号，或者是使用Github账号注册。  
Visit [Zerotier's official website](https://www.zerotier.com/),create a account.  
在新版本的Zerotier中，你需要创建一个组织，只需要输入任意名称后点击“Create Organization”，计划选择“Personal”，随后，Zerotier会自动创建一个局域网。  
As new version's zerotier,you need to create a org,just input a name and then tap "Create Organization",tne plan just choose "Personal",then,Zerotier will make a LAN.  
复制下来右上角的“Network ID”，发给加入者同时自己也要加入。  
Copy the Network ID,send to Joiner,Creator also need to join.
## Join LAN
在下载完Zerotier客户端之后，会在小图标托盘里面显示，左键点击后，点击“Join New Network”，输入“Network ID”，发起者需要在网页端批准加入。  
After Download Zerotier Client,it will be displayed in the small icon,LMB tap it,tap "Join New Network",input Network ID,Creator need to apply join at web panel.
