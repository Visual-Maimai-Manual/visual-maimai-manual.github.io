# 内网穿透：Easytier
> [!TIP]
> Easytier其实更适合中国大陆内的联机写谱，如果你同时需要与处于中国大陆外的好友写谱，请使用[Zerotier](zerotier.md)  
> Easytier works well in Mainland China. If you want to use it in other regions, check out [Zerotier](zerotier.md)  

Easytier是一个虚拟局域网工具，陶瓦联机（HMCL联机）也是基于Easytier。  
Easytier is a VLAN tool software.
## Download
可以在GitHub上面下载[Easytier](https://github.com/EasyTier/EasyTier/releases/tag/v2.4.5)  
You can get it on [Github](https://github.com/EasyTier/EasyTier/releases/tag/v2.4.5)  
## Start
在运行之后，可以看见默认为英文，可以在右上角设置里面调整为中文（简体）  
When first opened, the interface is in English.
在主页的配置网络选项下面，第一项保持不变，第二项的“网络名称”随便设置一个（比如```vmai114514```），网络密码随便设置（只要发起者和对方都能记住），最后，拉到最底端，点击“运行网络”，把网络名和密码发给好友。  
On the mainpage, do not change the first item. As for the second item's network name,just set a name of your choice, and a password. Then scroll to the bottom, click "Run Network",and send Network name and password to your friends.
## Join
在运行之后，可以看见默认为英文，可以在右上角设置里面调整为中文（简体）  
First run,it's english.
在主页的配置网络选项下面，第一项保持不变，第二项的“网络名称”设置为发起者所设置的网络名称“比如上面举例的```vmai114514```”，网络密码设置为发起者发给你的密码，最后，拉到最底端，点击“运行网络”，如果看到了多个加入者（一个发起者，一个服务器，一（多）个加入者）即为成功。  
In the mainpage,dont change the first item,the second item's network name,just set to your friend send to yours,and set a secret (Password),also set to your friend send to yours,then pull to the bottom,tap "Run Network",if you see a server,and some member,then it's running.
