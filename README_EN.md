# What is Visual Maimai?
Visual Maimai (aka VM) is a based on Unity's visualization community chart maker for [maimaiDX](https://en.wikipedia.org/wiki/Maimai_(video_game_series)) made by CH3COOOHH, released at Sep.,17,2024.

# 作出修改/贡献
If you find some wrong about the document,welcome to fix.
> **NOTE** <br>
> Please install git first and you need to learn Markdown.
1. [Fork this repo to your account.](https://github.com/Visual-Maimai-Manual/visual-maimai-manual.github.io/fork)  
ps:I recommend you change the repo name to (yourusername).github.io to preview at Internet.
2. Then clone the repo to your PC
```
git clone https://github.com/(yourusername)/(yourusername).github.io.git
```
3. Write it by markdown,and push to the repo.
```
# this is a sample
git add .
git commit -m what do you changed
git push
```
4. In your Github repo page,tap: Settings-Pages,change Source to“Github Action”
5. Waiting for deploy complete,then visit (yourusername).github.io,to preview it.  
6. At last,go back to your repo,tap "Contribute",then "Open Pull Request", wait for check.
# Deploy at your computer
> **NOTE**
> Install NodeJS and npm first.
1. Clone this repo to your computer/server
2. Open repo,Run:
```
npm install
```
